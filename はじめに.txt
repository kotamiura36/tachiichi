FORM8TER（フォーメイター）（ホーム画面アプリ版）

■ 入っているもの
index.html / manifest.webmanifest / sw.js / アイコン画像4つ
→ この7ファイルを同じ場所にそのまま置くだけで動きます。

■ GitHub Pagesで公開する手順（無料）
1. github.com でアカウントを作る
2. 右上「＋」→「New repository」→ 名前を tachiichi などにして「Public」で作成
3. 「uploading an existing file」をクリック → 7ファイルをまとめてドラッグ → 「Commit changes」
4. リポジトリの「Settings」→ 左の「Pages」
   → Branch を「main」/「/(root)」にして「Save」
5. 1〜2分後、 https://（ユーザー名）.github.io/tachiichi/ で開けます

■ iPhone / iPad に入れる
1. 上のURLを Safari で開く
2. 共有ボタン（□↑）→「ホーム画面に追加」
3. ホーム画面のFORM8TERアイコンから起動（全画面・オフラインでも動作）

■ 今までのデータを移す
1. 今のアーティファクト版のトップで「バックアップ」→ ファイルを保存
2. アプリ版のトップで「読み込み」→ そのファイルを選ぶ

■ すでにGitHub Pagesで公開している場合（今回の更新）
※ホーム画面のアイコン名は、一度アイコンを削除して「ホーム画面に追加」し直すと FORM8TER に変わります（削除する前に必ずバックアップを取ってください）。
7ファイルすべてを上書きでアップロードしてください（sw.js は v3 にしてあります）。
アプリを一度閉じて開き直すと新しい版になります。データはそのまま残ります。

■ アップデートするとき
index.html を差し替えて、sw.js の 'tachiichi-v3' を v4, v5… と上げてからアップロード。
アプリを一度閉じて開き直すと新しい版になります。

■ 注意
・データは端末ごと（そのアプリの中）に保存されます。機種変更や念のための保管には「バックアップ」を使ってください。
・PDFや画像の保存は、iPhoneでは共有シートが開くので「ファイルに保存」やAirDrop等を選びます。
